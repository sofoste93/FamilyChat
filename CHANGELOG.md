# Changelog

## 2.0.0 — 2026-10-04

- Add a responsive Java Swing desktop interface with warm green family branding.
- Start or join a room from the same screen; include roster, status, help and settings.
- Keep console server/client commands for learning and headless hosts.
- Package a private Java runtime for Windows, Linux, macOS Intel and Apple Silicon.
- Add real interface screenshots and a learner-friendly architecture guide.

- Repair the executable JAR manifest with one reliable launcher.

- Handle abrupt disconnects, UTF-8 messages and end-of-stream correctly.
- Reject empty, malformed and duplicate names.
- Make connected-user state thread-safe.
- Add a real two-client integration test and automated release workflow.
